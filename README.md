# Call Jack Pro — Website

Mobile-first marketing site for **Call Jack Pro**, a local locksmith & handyperson service.
Built to turn visitors (especially people locked out late at night) into phone calls.

**Stack:** Next.js 16 (App Router) · TypeScript · Tailwind CSS v4 · shadcn/ui-style primitives (Radix) · Lucide icons

## Quick start

```bash
npm install
cp .env.example .env.local   # then fill in the values
npm run dev                  # http://localhost:3000
```

Checks: `npm run lint` · `npm run typecheck` · `npm run build`

## Routes

| Route | Purpose |
|---|---|
| `/` | Homepage — hero, services, trust strip, after-midnight section, contact CTA |
| `/lockout` | Emergency lockout landing page (call-first; good target for Local Services Ads) |
| `/locksmith` | Locksmith services: lockouts, rekeying, repair, keys |
| `/services` | All services with anchors `#locksmith`, `#home-repairs`, `#installation`, `#maintenance` |
| `/handyman` | Scheduled handyperson work + request form (no emergency messaging) |
| `/about` | About Jack / how we work |
| `/contact` | Call card, hours, service area, request form (`#request`) |
| `/areas/<city>` | One local landing page per city in `NEXT_PUBLIC_SERVICE_AREAS` (none until areas are set) |

`/sitemap.xml`, `/robots.txt`, `icon.png` and `apple-icon.png` are generated by the App Router.

## Where things live

```
src/config/business.ts     ← phone, URL, hours, service areas, address (all env-driven)
src/config/services.ts     ← service copy + request-form categories
src/config/navigation.ts   ← nav + services menu
src/components/            ← Header, MobileCallBar, Footer, HeroSection, ServicesGrid,
                             ServiceCard, TrustFeatures, EmergencyNightSection, ContactCTA,
                             ServiceRequestForm, PrimaryCTA (CallButton / HelpButton) …
src/lib/lead-delivery.ts   ← form delivery integration interface (webhook / Resend)
src/lib/structured-data.tsx← LocalBusiness/Locksmith, Service, Breadcrumb JSON-LD
public/images/             ← illustrations derived from the supplied artwork
```

No phone number is hard-coded in components — every `tel:` link uses `business.phone`.

## Service request form

The form validates on the client and server, and has spam protection: a honeypot field, a minimum
fill-time check, and a per-IP rate limit (in-memory and per instance; use Redis/Upstash if you need
strict limits across serverless instances).

**It only accepts requests once a delivery provider is configured.** Until then, it shows a
"not connected yet" notice and tells visitors to call. It never fakes a success message.

Configure at least one provider (server-side env vars):

* **Webhook:** `LEAD_WEBHOOK_URL` (+ optional `LEAD_WEBHOOK_SECRET`, sent as a Bearer token). The webhook receives
  `{ type: "service_request", business, lead: { name, phone, service, serviceLabel, emergency, location, description, preferredTime, submittedAt, source } }`.
* **Email via Resend:** `RESEND_API_KEY`, `LEAD_EMAIL_TO`, `LEAD_EMAIL_FROM`. Emergency categories get an `[URGENT]` subject.

If both are set, the lead is sent to both. The visitor sees success if at least one accepts it.
To add another provider, implement `LeadDeliveryProvider` in `src/lib/lead-delivery.ts`.

Pages are statically prerendered, so set these env vars **before building/deploying**.

## Design system

* Colors (`src/app/globals.css`): ink `#111111`, white, brand yellow `#FFCC00`, cream `#FFF8DD`, mist `#F5F5F5`.
  Yellow is the only chromatic accent and is always paired with black text.
* Type: Poppins ExtraBold Italic for headings (`font-heading`), Nunito Sans for body.
* The wordmark is purely typographic with a yellow swoosh: no padlock, house, or key.
* Illustrations: `jack-hero-van.webp` (hero, van facing left behind Jack), `jack-night.webp` (cut-out Jack
  for the night scene, composited over the SVG `NightScene`), `jack-portrait.webp`, `jack-face.webp`.

## Launch checklist

- [x] Production domain: https://www.calljackpro.com (built-in default; override with `NEXT_PUBLIC_SITE_URL` for previews)
- [x] No physical address (mobile service-area business): the address stays unset and is never displayed or marked up
- [ ] Form delivery provider (webhook or Resend)
- [ ] Confirmed service areas: `NEXT_PUBLIC_SERVICE_AREAS` (creates the `/areas/<city>` pages) and `NEXT_PUBLIC_REGION_LABEL` (adds the region to the homepage title)

- [ ] Confirm the 24/7 lockout coverage claim matches real operations (`NEXT_PUBLIC_LOCKOUT_24_7`)

- [ ] Review copy for any licensing/insurance statements you want to add. None are claimed today.
